## Features

- **Luxury Dark Glassmorphic Design**: A clean, high-performance aesthetic with translucent elements.
- **Interactive AI & ML Playground**: Live in-browser simulations of XGBoost disease risk models, NLP TF-IDF spam classifiers, and crop advisors.
- **Code & ML Pipeline Explorer**: Interactive Python script viewer with simulated terminal execution logs.
- **Command Palette (`Ctrl+K`)**: Keyboard-first search & instant navigation across all projects, skills, and tools.
- **Mobile Quick Action Dock**: Floating glass navigation bar for seamless mobile phone navigation.
- **Audio Sound Synthesizer**: High-tech Web Audio API click and feedback chimes with mute toggle.
- **Fully Responsive & Clean**: 100% optimized for desktops, laptops, tablets, and smartphones.
