## Features

- **Premium Glassmorphic Design**: A modern, high-tech aesthetic with translucent elements.
- **Dynamic Background**: Interactive particle system powered by `particles.js`.
- **Custom Interaction**: Advanced custom cursor with follower effect for enhanced UX.
- **Multi-Theme Switching**: Toggle between three dark palettes — Emerald, Cyber Neon, and Tech Gold — with a saved preference via `localStorage`.
- **Command Palette (Ctrl+K)**: Quick-search navigation across sections, projects, skills, and certifications.
- **Interactive AI Lab**: Live in-browser simulations of the Revive, HamOrSpam, and FarmAIQ ML models.
- **Code & Pipeline Explorer**: Tabbed code viewer with a simulated terminal execution console.
- **Fully Responsive**: Optimized for all devices, from desktops to mobile phones.
- **AOS Animations**: Smooth scroll animations using the `Animate On Scroll` library.
- **Typing Animation**: Dynamic hero section highlighting my core roles.
- **Project Filtering**: Categorized project showcase for easy navigation.
- **Interactive Stats**: Animated counters for key milestones and achievements.
- **UI Sound Effects**: Optional Web Audio API sound feedback on interactions (toggleable, muted state persists).

Smart agriculture recommendation system with crop recommendation and disease detection pipelines using Random Forest and CNNs.

## Getting Started

### **Prerequisites**

- A modern web browser.
- Git (optional, for cloning).

### **Installation**

1. Clone the repository:

   ```bash
   git clone https://github.com/mohdshamii/mohdshamii.github.io.git
   ```

2. Navigate to the project directory:

   ```bash
   cd mohdshamii.github.io
   ```

3. Open `index.html` in your browser.
